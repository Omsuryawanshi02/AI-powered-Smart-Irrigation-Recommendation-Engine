Getting Started

  1. 1. Make sure the backend server is running on http://localhost:8000
  2. 2. Click "Check Health" to verify the backend is responding
  3. 3. Use the test buttons to verify API endpoints are working
  4. 4. Configure the API URL if your backend is on a different server
  5. 5. Navigate to the dashboard or add fields to start using AquaSmart
